# ExtractLoz data tables

These files are copied unchanged from Aldo J. Nunez's
[Loz](https://github.com/aldonunez/Loz) (`Tools/ExtractLoz/Data/`), Apache
License 2.0. They are hand-made tables, not ROM data: sprite-sheet arrangement
maps, per-object attributes, and the recipe for rebuilding the game's NSF.
`tools/gen-extract-tables.py` turns them into `src/extract/RomExtractTables.gen.h`.
